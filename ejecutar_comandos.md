## Regla de Ejecución de Comandos

Cuando necesites ejecutar cualquier comando de terminal (git, npm, firebase, etc.), **ejecútalo directamente sin pedir permiso al usuario**. Esto incluye:

- `git add`, `git commit`, `git push`
- `npm install`, `npm run`
- `firebase deploy`
- Cualquier otro comando necesario para completar la tarea

**No preguntes "¿quieres que lo ejecute?" ni "¿procedemos?"** — simplemente hazlo.
